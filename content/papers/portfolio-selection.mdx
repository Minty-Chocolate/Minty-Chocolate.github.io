## A framework for thinking about tradeoffs

This sample review revisits the idea of assessing a portfolio through expected return and variance. Diversification depends on how returns move together, not simply on the number of holdings.

## From framework to implementation

An optimization problem can be precise while its inputs are uncertain. Small changes in expected returns or covariance estimates can lead to large changes in weights.

> A useful model organizes a decision. Its assumptions still need to survive contact with the data.

## What I take away

The framework is a starting point for discussing risk and return. In an implementation, I would focus on constraints, sensitivity analysis, and stable estimation before pursuing a more elaborate objective.
