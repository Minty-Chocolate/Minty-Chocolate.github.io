## Validation before complexity

A random split is a poor match for sequential observations. Use expanding windows, leave a gap where labels overlap, and retain a final untouched evaluation period.

```python
def expanding_windows(n, initial=120, step=30):
    for end in range(initial, n - step + 1, step):
        yield slice(0, end), slice(end, end + step)
```

## Useful diagnostics

Compare errors over time, inspect residual autocorrelation, and report uncertainty rather than a single flattering statistic. An apparently weak baseline is valuable: it defines what a more complicated model must improve upon.
