## Keep the experiment legible

A research result should come with enough context to reproduce it. This illustrative toolkit pairs a configuration file with a seed, a data description, and a short record of the choices made.

```typescript
type Experiment = {
  name: string;
  seed: number;
  lookback: number;
};

const experiment: Experiment = {
  name: "baseline-allocation",
  seed: 42,
  lookback: 252,
};
```

## Design principles

1. Keep configuration separate from calculations.
2. Fail early when required inputs are absent.
3. Save assumptions alongside outputs.
