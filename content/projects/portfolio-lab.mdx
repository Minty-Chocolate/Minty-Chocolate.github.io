## The question

How much does an allocation change when our estimate of risk changes? This illustrative project compares equal weighting, minimum variance, and a simple risk-budget approach using synthetic returns.

  Independent demonstration project. Results below describe a proposed
  experiment, not investment advice or a claim of live performance.

## A small, transparent model

For portfolio weights $w$ and covariance estimate $\Sigma$, the minimum-variance problem is:

$$
\min_w \; w^\top \Sigma w \quad \text{subject to} \quad \mathbf{1}^\top w = 1, \; w \geq 0.
$$

```python
import numpy as np

rng = np.random.default_rng(42)
returns = rng.normal(0, 0.01, size=(252, 4))
covariance = np.cov(returns, rowvar=False)
weights = np.full(4, 0.25)
portfolio_risk = np.sqrt(weights @ covariance @ weights)
```
